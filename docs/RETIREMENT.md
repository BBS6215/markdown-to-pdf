# Hosted-service retirement / 线上服务退出

**Date / 日期:** 2026-11-16

The original hosted website at `markdown-to-pdf.app` is being retired. Source code, complete Git history, schema migrations, documentation, and pre-shutdown screenshots are preserved. This repository remains open to feedback and contributions; it is not archived.

原站正在停止运营。保留源码、完整 Git 历史、数据库迁移、文档和停服前截图；仓库继续接收 Issues 和 PR，不设为归档。账号、转换历史和其他业务数据随云项目删除，不另作备份。源码中仍保留登录和历史功能，供自行部署者配置自己的资源。

## Publication before shutdown / 下线前发布

- Real English PDF and Chinese Word screenshots are stored in `docs/images/` and embedded in both READMEs.
- The original MIT license is retained; bundled font license texts are included.
- Original conversion code and SQL migrations remain available for self-hosting.
- The retired domain and original cloud/login credentials must not be reused in a fork.

## Operational status / 处置状态

At this publication, open-source preparation is complete and cloud cleanup is pending. This section will be updated only after the corresponding operations have been verified. / 本次发布先完成开源准备；云端清理仍待执行，验证后再更新本节，不以计划代替完成。
